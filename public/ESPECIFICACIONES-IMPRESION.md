# Especificaciones de Impresión - Banners iMove

## Formatos de Exportación Disponibles

### 1. PNG Alta Resolución (Recomendado para Impresión Digital)
- **Resolución:** 3200 x 4800 píxeles (10x scale)
- **DPI Efectivo:** ~254 DPI a tamaño real de impresión
- **Tamaño de Impresión:** 80 x 120 cm
- **Calidad:** Máxima (sin compresión)
- **Uso:** Impresión digital de gran formato, gigantografías

### 2. PDF (Recomendado para Imprentas)
- **Dimensiones:** 800 x 1200 mm (80 x 120 cm)
- **Resolución Interna:** 2560 x 3840 píxeles (8x scale)
- **Formato:** JPEG embebido con 98% de calidad
- **Compresión:** Optimizada
- **Uso:** Envío directo a imprentas, facilita el proceso de producción

## Especificaciones Técnicas de los Banners

### Dimensiones
- **Base:** 320 x 480 px (ratio 2:3)
- **Impresión Final:** 80 x 120 cm
- **Ratio de Aspecto:** 2:3 (perfecto para pendones verticales)

### Áreas de Seguridad
- **Superior:** 15 px (~1 cm en impresión)
- **Inferior:** 15 px (~1 cm en impresión)
- **Propósito:** Espacio para amarrar, guindar o fijar el banner
- **Visual:** Patrón rayado diagonal semi-transparente

### Colores Corporativos
- **Naranja Principal:** #FF6B35
- **Naranja Oscuro:** #E85D2A
- **Naranja Claro:** #FF8F6B
- **Teal/Turquesa:** #4ECDC4
- **Negro:** #000000 - #1a1a1a
- **Amarillo:** #FFD700 (banner de reclutamiento)

### Tipografía
- **Fuente Principal:** Urbanist (Google Fonts)
- **Pesos:** 100-900 (Variable)
- **Disponible en:** https://fonts.google.com/specimen/Urbanist

## Proceso de Descarga

### Desde la Aplicación Web
1. Navegar a: `http://localhost:4200/pages/advertising`
2. Seleccionar el banner deseado
3. Elegir formato:
   - **PNG HD:** Para impresión digital o edición adicional
   - **PDF:** Para envío directo a imprenta

### Nomenclatura de Archivos
- **PNG:** `iMove-[Nombre]-10x-3200x4800.png`
- **PDF:** `iMove-[Nombre]-Imprenta.pdf`

## Recomendaciones para la Imprenta

### Preparación del Archivo
1. **Verificar dimensiones:** 80 x 120 cm exactos
2. **Revisar áreas de seguridad:** Contenido importante alejado de bordes
3. **Formato recomendado:** PDF para mejor compatibilidad

### Material de Impresión
- **Lona vinílica:** 13 oz para exteriores
- **Banner mate:** Para interiores
- **Microperforado:** Para ventanas

### Acabados
- **Ojales:** En área de seguridad superior e inferior
- **Espaciado de ojales:** Cada 50 cm
- **Refuerzo:** En esquinas y ojales

### Sangrado (Bleed)
- **Incluido:** Áreas de seguridad de 1 cm
- **Adicional:** Si la imprenta requiere más, solicitar ajuste

## Solución de Problemas

### La imagen se ve pixelada
- Usar escala 10x (3200x4800px)
- Descargar en formato PNG HD
- Verificar que la imprenta no está sobre-escalando

### Los colores no coinciden
- Verificar perfil de color: sRGB
- Solicitar impresión en CMYK
- Proporcionar códigos HEX para referencia

### Elementos cortados
- Verificar áreas de seguridad (1 cm bordes)
- Contenido importante debe estar a 2 cm de bordes
- Revisar sangrado con la imprenta
